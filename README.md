# Street Heat

Street Heat is a neon-soaked top-down browser chase game built with Three.js and Vite. You drift through a modular city, dodge police pressure, chase score multipliers, unlock cars, buy upgrades, and survive dynamic events, contracts, and escalating heat tiers.

## Features

- Top-down driving with drift, nitro, collisions, and combo scoring
- Modular city with districts, POIs, weather, events, and destructible props
- Garage progression with unlockable vehicles and permanent upgrades
- Wanted system with police roles, roadblocks, spikes, and a late-heat helicopter
- Persistent profile with cash, best score, achievements, and contracts

## Tech

- `Three.js` for rendering
- `Vite` for local development and builds
- Plain ES modules with DOM HUD overlays

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the local Vite server on `127.0.0.1`
- `npm run build` creates the production build
- `npm run preview` previews the production build locally
- `npm run test` runs the logic smoke test
